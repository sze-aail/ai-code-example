# Exercises - Lec13

Javasolt mini-feladatok:

1. BPTT: novelje a szekvenciahosszt, es merje a gradiens normajat.
2. LSTM: allitsa a forget gate biast 0-ra es 1-re, hasonlitsa ossze.
3. Attention: ellenorizze kezzel az elso sor softmax ertekeit.
4. Multi-head: bizonyitsa, hogy `heads=1` visszaadja az egyfeju alakot.
5. Transformer blokk: pre-norm vs post-norm konvergencia.
6. VAE: beta sweep (`beta=0.5,1,4`) es rekonstrukcio/latent tradeoff.
7. DCGAN: mode collapse detektalas kepmintakon.
8. Diffusion: tanitsa kulonbozo `T` lepesszammal.
9. HF pipeline: probaljon mas magyar vagy multilingual modelleket.
10. Mini RAG: bovitett dokumentumhalmaz, top-k hatas merese.
